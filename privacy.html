Privacy Policy

Last updated: 17 November 2026.

This policy describes the owner-operated Pip and Bolo Publisher application and this information page.

Data accessed and purpose

With the channel owner's authorization, the application accesses the YouTube channel identifier and basic channel information; uploaded video identifiers, titles, descriptions, tags, audience designation, privacy, scheduling and processing status; and aggregate channel analytics such as daily views, watch time and subscriptions. It handles video files and metadata supplied by the owner. These data support uploads, scheduling, performance reporting and prevention of duplicate uploads.

The application stores an OAuth refresh token and client configuration to maintain authorized access. It does not request or store the owner's Google password. The application does not seek personal information from children and is not an interactive service for children.

Storage and service providers

Owner-controlled local project storage and a private GitHub repository hold project files, publication records and related configuration. Cloud jobs run in GitHub Actions. The cloud OAuth connection is stored in encrypted GitHub Actions secrets, not in public source files. Authorized workflow maintainers can use that connection. Google and YouTube process API requests and video uploads. This information page contains no embedded analytics, advertising, forms or sign-in tools; the hosting provider may process ordinary network and access logs.

Use and disclosure

Google user data are used only to operate and improve the owner's channel publishing functions. They are not sold, used for targeted advertising or supplied to AI providers to train generalized models. Publicly released videos and their public metadata are visible on YouTube only after owner-approved publication. Private credentials, private analytics and publication records are not included on this page.

Pip and Bolo Publisher's use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Credentials and publication records are retained while the owner uses the application. The current implementation requires the owner to remove stored credentials and records when disconnecting; revoking Google access alone does not erase existing local or GitHub copies. The owner can request removal through the contact address below. Published YouTube videos remain on YouTube until separately removed through YouTube.

Control and contact

The owner can revoke access at Google Account permissions. Revocation prevents subsequent authorized API calls once existing access expires or is invalidated. For data access, correction or deletion requests, contact pipandbolo@gmail.com.

YouTube use is also subject to the YouTube Terms of Service and Google Privacy Policy.
