Pip and Bolo Publisher

A private publishing utility operated by the owner of the Pip and Bolo YouTube channel. It prepares channel metadata, uploads channel-owner-approved videos, manages publication records and supports scheduling and channel performance reports.

This is an owner-operated tool, not a public sign-up service. This information page does not provide access to the publisher or its private files.

Google and YouTube access

The tool uses the YouTube Data API for the owner's channel and read-only YouTube Analytics access. The current YouTube authorization scope technically permits managing and deleting videos, comments, ratings and captions. The tool's implemented publishing workflow uses channel identification, video upload, video status and metadata operations; it does not implement comment moderation or video deletion.

The owner reviews content before public release. A successful upload test is not approval to publish an episode.
